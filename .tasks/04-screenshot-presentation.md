# 04 — Reduce screenshot prominence

Status: captured; not planned.

## Owner feedback

> the screenshots ruin the color style of the website. perhaps we can either make it smaller, or text only (see screenshots) and opens a modal.

## Requested outcome

- Keep third-party/product screenshot colors from dominating the site's green visual identity.
- Consider smaller image previews **or** text-only triggers that open screenshots in a modal.
- Preserve access to the authentic Redbook and Cards Guide PH screenshots.

## Open decisions

- Choose smaller previews, text-only modal triggers, or an explicitly agreed combination.
- Decide which placements change: hero, personal-project area, case studies, or all of them.
- Identify the reference screenshot(s) meant by “see screenshots”; do not invent a reference or assume an existing input is the intended example.

## Completion criteria for the eventual change

- Screenshot presentation is subordinate to the site's existing colors and typography.
- The homepage does not regain the duplicate Redbook gallery previously removed from the work preview.
- Original images remain unmodified and legible at full size; do not recolor them to force theme matching.
- If a modal is chosen, it has labeled content, keyboard opening/closing, Escape support, sensible focus handling/return, phone-friendly sizing, and accessible controls.
- Image alternatives, loading/error states, both themes, and a usable no-JavaScript full-image path remain available.
